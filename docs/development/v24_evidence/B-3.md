## 5. Known limits

1. **Stored look-ahead is a boolean.** `estimation_runs` stores only
   `look_ahead_safe`; with no schema change allowed, the stored view renders
   「已驗證安全（布林值）」/「未驗證安全（布林值）」 instead of inventing one of the
   four V2.2 states. Live runs still show the real `look_ahead_status`.
2. **Stored quarter/scope/disclosure come from the inputs snapshot.** The B3-08
   `inputs` field is read-only and filled by the service; the GUI never reads
   `_qdii_estimate_inputs.json` or the database itself. A run whose inputs
   payload lacks those keys shows `—`.
3. **Handover is not persistence.** The analysis path does not pass a
   repository, so the handover window says 「未寫入資料庫（分析結果交接）」 and adds a
   warning; it is never listed in history.
4. **History ordering and limits belong to the service.** The GUI passes the
   fund filter through and renders the rows verbatim; it does not re-sort or
   patch missing values.
5. **A-10 is a scripted session, not a human one.** It stays as recorded there;
   B-16 is the real-desktop acceptance and remains pending for B-4.
