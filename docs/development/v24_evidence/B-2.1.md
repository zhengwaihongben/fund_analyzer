## 2. Defects found by the six added tests

The tests B2.1-13 … B2.1-18 were written against the shipped code and
produced four failures before the fix:

| Test | Symptom |
| --- | --- |
| B2.1-13 unmatched snapshot | label `執行快照 JSON` claimed although no ticker matched |
| B2.1-14 unmatched latest JSON | label `最新 JSON` claimed although no ticker matched |
| B2.1-15 matched but useless snapshot | label claimed although the snapshot added nothing |
| B2.1-18 contribution present, status missing | `None != 'estimated'` — status never merged |

Root causes: the resolver appended a label whenever `rows` was non-empty,
without checking whether that source supplied data; and
`_merge_contributions()` skipped the whole row when a contribution already
existed, so `status` could never be filled independently.

## 3. Fixes

`fa/application/estimation.py`:

1. `_merge_contributions()` now returns the number of rows that actually
   received a field (`int`), and the resolver only appends a source label when
   that number is non-zero (or, for the build-from-scratch path, when the built
   list is non-empty). An existing source file is never evidence that it was
   used.
2. `_merge_contributions()` merges the two fields independently:

   | SQLite field | Source field | Result |
   | --- | --- | --- |
   | contribution present | contribution differs | SQLite kept |
   | contribution missing | contribution valid | source used |
   | status `None` | status valid | source used |
   | status `""` | status valid | source used |
   | status `ok` | status valid | source used |
   | status non-`ok` | status differs | SQLite kept |

3. New `_needs_merge()` decides whether a snapshot/latest-JSON read is worth
   doing at all: rows are missing, or some row lacks a contribution, or some
   row's status is `None`/`""`/`ok`. Without it a complete-contribution row
   never received the snapshot's finer status (B2.1-18).

Priority order is unchanged: SQLite summary → run snapshot → latest JSON
(same `run_id` only) → `—`. No new data source was introduced.
