# D-10 — real desktop: open a stored run, export and open the file (manual)

Status: **pending — requires the lead's interactive Windows desktop session.**
The automated parts (preview text == renderer output, export bytes ==
renderer output, bounded close) are already covered by
`tests/test_reports_history.py` and `tests/test_application_reporting.py`.

## Procedure

1. Launch the app (`launch.vbs`, or `python fund_analyzer_gui.py`).
2. Open the 「報告與歷史」 tab and press 「開啟歷史視窗」.
3. In 「回測歷史」, pick a stored run, wait for the preview to fill and confirm
   the text starts with `# Backtest report`.
4. Press 「匯出」 and check the path label shows
   `output/reports/<run_id>.md`; open the file and compare it with the preview.
5. Repeat in 「估算歷史」: pick a stored run, preview, export, open
   `output/reports/<run_id>_estimate.md`.
6. Type a filter (fund code / strategy id), press 「重新整理」 and confirm only
   matching rows remain.
7. Close the window while a report is loading; confirm it closes within about
   two seconds and the main window is still responsive.
8. With the database unchanged before/after (no new rows, no edited rows),
   confirm that browsing and exporting never modified history.

## Evidence to attach

- Two screenshots: the backtest preview and the exported file opened.
- The filter result screenshot.
- Date, machine, Python/Tk version.
- Confirmation that `data/database/fund_analyzer.db` row counts were unchanged.
