## 2. Defect proven and fixed

`_as_float()` rejected `None`, `bool`, non-numeric text and NaN, but passed
±infinity straight through. A snapshot holding with `"weight": Infinity`
would therefore have been shown as a weight of ∞ — a financial value no
source ever produced.

Before (three failing tests):

```
FAIL: test_positive_infinity_is_not_financial   AssertionError: inf is not None : weight
FAIL: test_negative_infinity_is_not_financial   AssertionError: -inf is not None
FAIL: test_every_numeric_field_is_guarded       AssertionError: inf is not None : weight
```

After:

```python
if not math.isfinite(number):
    return None
```

`_as_float` is the single gate used by every numeric field, so the fix covers
`weight`, `local_return`, `fx_return`, `cny_return` and `contribution` at once.

## 2.1 Oversized integers (B2.5-06…08)

**额外边界**：`float(10 ** 1000)` 直接抛 `OverflowError`，根本到不了
`math.isfinite()`；JSON 允许任意精度整数，因此旧版 `_as_float()` 会让一笔
历史 holdings 的读取整体中断，而不是把无效值转成 `None`。

修正：`except (TypeError, ValueError, OverflowError)`。

新增测试：`test_oversized_positive_integer_is_not_financial`、
`test_oversized_negative_integer_is_not_financial`、
`test_oversized_integer_in_json_holdings_does_not_abort_history_read`
（后者经真实 JSON → `load_estimate()` 的 Stored Mode 路径，验证 ticker 仍可读、
两个数值字段为 `None`、不重新估值、不写 SQLite、不改 JSON）。

## 6. Abnormal presentation values (B2.5-04)

No clamping, no recalculation, no dedupe — the layer reflects the record:

- zero weight `0.0`, negative weight `-0.1`, tiny `1e-12`, `1.5` above 100 %,
  `1e308` / `5e-324` all preserved
  (`test_zero_weight_is_kept`, `test_negative_weight_is_kept`,
  `test_tiny_weight_is_kept`, `test_weight_above_one_is_not_clamped`,
  `test_extreme_magnitudes_are_kept_when_finite`).
- empty holdings → no rows; duplicate tickers → both rows, not merged
  (`test_empty_holdings_produce_no_rows`,
  `test_duplicate_tickers_are_preserved_not_merged`).
- invalid date strings are passed through verbatim (the service does not parse
  dates) — `test_invalid_date_strings_are_presented_verbatim`.
- mixed `None`/`""`/`"abc"`/`"0.2"` rows do not raise —
  `test_mixed_missing_and_invalid_values_do_not_raise`.

cover the broader write-spy and schema/version checks.)
