## 6. Fix — E-02a (2026-11-21) and the post-fix readings

What changed (startup path only, no analysis/data/backtesting/reporting/CLI behaviour):

| File | Change |
|---|---|
| `fa/gui/app.py` | `fa.pipeline`, `fa.viz.master`, `QdiiEstimateWindow`, `BacktestWindow`, `HistoryWindow`, `PostMarketWindow` imports moved into the handlers that open them; estimation/backtest/reports tab content is built on first selection (`_tab_builders`, `_ensure_tab`, one `<<NotebookTabChanged>>` binding); no Repository is opened and no DB is initialised at startup |
| `fa/gui/__init__.py` | `main` is exported lazily (PEP 562) — importing the package no longer pulls `requests` through `fa.utils.net` (0.94 s) |
| `fa/gui/app.py` | removed the 📊 emoji from the 打开综合报告 button: Tk's emoji glyph resolution cost **2.05 s** of the build in this environment |

New guard: `tests/test_gui_startup.py` (a) imports `fa.gui.app` in a child process and fails if `pandas`, `matplotlib`, `fa.pipeline` or `fa.viz.master` appear in `sys.modules`; (b) confirms in a child process that only the analysis tab is built at startup and that `_ensure_tab("estimation")` creates it.
